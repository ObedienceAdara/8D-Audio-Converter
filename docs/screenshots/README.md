# Screenshot capture guide

Capture these views from the running application for the public README:

1. `01-workspace.png` — conversion workspace with file selection, presets, DSP controls, and output format selection.
2. `02-waveform-trajectory.png` — selected source waveform beside the live spatial trajectory.
3. `03-progress.png` — queued/processing state showing progress percentage, current stage, and queue depth.
4. `04-result.png` — completed output preview, rendered waveform, metrics, and download control.
5. `05-batch.png` — multi-file conversion with per-file status and aggregate progress.

Recommended captures: 1440px desktop width and one mobile width. Use real application output only; do not fabricate audio metrics or screenshots.
